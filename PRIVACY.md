# Privacy

This is a static portfolio. It does not use cookies, localStorage, sessionStorage, analytics, trackers, or third-party runtime requests.

## Public data

- Name, city, professional email, education, certifications, employment history, project links, portrait, and resume are published intentionally.
- No phone number is intentionally published. If you find one in any asset, please report it (see `security.txt`).
- External links (GitHub, LinkedIn, Google Drive, Coursera, Render) are visited only when you click them. Their privacy policies apply after navigation.

## Hosting logs

The site is hosted on GitHub Pages. GitHub may process standard request logs (IP address, user agent, timestamp) under GitHub's privacy statement. The owner runs no custom analytics pipeline.

## Removal

To request removal of public personal data, email the contact address in `security.txt`. The owner will verify the request and remove or redact the data where feasible. Public git history, forks, and third-party caches may retain copies; what can and cannot be removed will be documented honestly in the reply.
